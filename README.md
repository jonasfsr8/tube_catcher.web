# 🌐 Video Download Web

Frontend desenvolvido com Vite + React para interação com a plataforma de download de vídeos.

## 🚀 Tecnologias

- React
- Vite
- Axios
- React Router
- Context API

## 📌 Funcionalidades

- Tela de login e cadastro
- Autenticação de usuários
- Solicitação de download de vídeos
- Escolha de formatos disponíveis
- Interface responsiva

## 🔗 Integração

A aplicação se comunica com a API ASP.NET Core para autenticação e envio das solicitações de download.

## ▶️ Executando o projeto

```bash
npm install
npm run dev
